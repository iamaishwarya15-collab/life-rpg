# Life RPG 🎮

A gamified full-stack Django web app that turns real-life tasks into RPG quests.

## Features

- 🔐 User signup and login
- ⚔️ Create, edit, delete and complete quests
- ⚡ XP and non-linear leveling
- 🪙 Gold rewards
- 🔥 Daily streaks
- 📊 Character attributes
- 🏆 Achievements
- 🛒 Virtual shop
- 🎒 Inventory
- 💾 SQLite database persistence

## Tech Stack

- Python
- Django
- SQLite
- HTML
- CSS
- JavaScript

## Run Locally

```bash
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
